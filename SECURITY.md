# Security Policy

## Supported Versions

As there are no official releases yet, only the current commit is supported. If you are running a outdated commit downlaod the latest commit and reinstall.

## Reporting a Vulnerability

If you discover a vulnerabiltiy in the latest commit (or in a outdated commit but the vunlnerability has not been patched) email the developers at Badwolfunit@icloud.com or open a private vulnerability report. Please discribe the problem in full including the exploits you can use against it.
