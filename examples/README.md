# Example Datasheets

This directory contains example datasheets to help you understand the JSON format used by Warhammer Gadget.

## Using Example Datasheets

To use these examples:

1. Copy any example datasheet to your config directory:
   ```bash
   cp examples/example_datasheet.json ~/.config/warhammer-gadget/datasheets/
   ```

2. Run the application and select the datasheet option

3. Enter the name of the datasheet (without the .json extension)

## Creating Your Own Datasheets

Use the `template_datasheet.json` in `warhammer_gadget/datasheet_template/` as a starting point for creating your own datasheets.
